## 🛒 중고 물품 경매 플랫폼

사용자가 직접 상품을 등록하고 입찰/낙찰할 수 있는 **중고 거래 웹사이트**로,  
편리한 거래 경험을 제공하기 위해 개발한 프로젝트

---

### 📅 개발 기간
2024.12 ~ 2025.02 (3개월)

### 👥 참여 인원
팀원 3명

---

### 🚀 주요 기능
- **회원 관리**: 회원가입, 로그인/로그아웃, 계정 비활성화  
- **상품 관리**: 상품 CRUD, 입찰 및 낙찰, 검색 기능 구현
- **채팅 기능**: 채팅방 생성/조회/삭제, 메시지 전송, 거래 완료 처리  
- **마이페이지**: 회원 정보 조회/수정, 상품 입찰·낙찰 취소
- **해결 필요**: 이미지 관리<br>
  S3 연동 문제 해결 중으로 이미지 등록 및 표시 불가, 배포 링크에서는 채팅 화면 확인 제한적임.

---

### 🛠 기술 스택
- **Backend**: Spring Boot, Spring Security, Spring Data JPA, JWT  
- **Database**: MySQL  
- **Dev Tools**: IntelliJ IDEA, Postman  
- **Infra**: AWS EC2, RDS  

---

### 📈 성과 및 배운 점
- RESTful API 설계 및 JWT 기반 인증/인가 구현  
- WebSocket을 활용한 실시간 1:1 채팅 서버 설계  
- AWS EC2와 RDS를 이용한 배포 및 서버 운영  
- 환경 변수 및 `bootJar` 기반 프로덕션 배포 경험  
- 팀 협업 과정에서 요구사항 분석 및 문제 해결 능력 강화
